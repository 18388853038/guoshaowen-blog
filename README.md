## 🚀 安装指南

1. 从 [Releases 页面](https://github.com/18388853038/guoshaowen-blog/releases) 下载最新安装包
2. 双击运行安装程序
3. 选择安装路径（或使用默认路径）
4. 安装完成后桌面自动生成快捷方式
5. 首次启动会自动配置环境并启动后端服务

## ✨ 功能特性

- **AI 助手对话** — 内置企业级 AI CEO 助手，支持多轮对话与任务执行
- **桌面操作** — 截图、鼠标控制、窗口管理、键盘输入
- **文件管理** — 文件读写、目录操作、JSON/CSV 解析
- **工具扩展** — 支持动态安装/卸载自定义工具
- **任务编排** — 通过分身（Sub-Agent）并行执行复杂任务
- **内存引擎** — 持久化记忆与检索

## 🔧 技术栈

- **前端**：Vue 3 + Vite
- **后端**：Node.js + Express + WebSocket
- **桌面框架**：Electron 42
- **AI 引擎**：OpenClaw 多模型支持
- **构建工具**：electron-builder

## 📋 系统要求

- Windows 10/11（64位）
- 4GB+ 内存
- 500MB+ 磁盘空间
