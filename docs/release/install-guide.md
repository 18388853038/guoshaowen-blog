# ECompany Asst — 安装指南

> 适用于 Windows 10/11 64位系统

---

## 系统要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10 64位 | Windows 11 64位 |
| 内存 | 4 GB | 8 GB+ |
| 磁盘空间 | 500 MB | 1 GB+ |
| 网络 | 可访问互联网 | 稳定宽带 |
| 运行时 | 无需预装 | Node.js 可选（后端调试用） |

## 安装步骤

### 第一步：下载安装包

从 [Releases 页面](https://github.com/18388853038/guoshaowen-blog/releases) 下载最新版本：

- `ECompany.Asst.Setup.2.0.0.exe` — 主安装程序

### 第二步：运行安装程序

1. 双击 `ECompany.Asst.Setup.2.0.0.exe`
2. 如果 Windows 显示安全警告，点击 **更多信息** → **仍要运行**
3. 选择安装语言（默认简体中文）
4. 同意许可协议
5. 选择安装目录（建议使用默认路径）
6. 选择是否创建桌面快捷方式
7. 点击 **安装** 等待完成

### 第三步：首次启动

1. 安装完成后，勾选 **运行 ECompany Asst** 并点击 **完成**
2. 程序会自动初始化后端服务（大约需要 5-10 秒）
3. 首次启动时会自动完成以下配置：
   - 创建应用数据目录
   - 初始化环境变量
   - 启动本地 API 服务
   - 加载核心模块（OpenClaw 引擎、工具集）

## 常见问题

### Q: 提示"Windows 保护了你的电脑"

这是 Windows Defender SmartScreen 对新发布应用的常规拦截。点击 **更多信息** → **仍要运行** 即可。随着下载量增加，此提示会逐渐消失。

### Q: 安装后无法启动

检查以下可能：
1. **端口冲突** — 程序默认使用 8005 端口。检查是否有其他程序占用：
   ```
   netstat -ano | findstr :8005
   ```
2. **依赖缺失** — 确保安装包完整下载（SHA256 可在 Releases 页面验证）
3. **安全软件拦截** — 临时关闭杀毒软件后重试

### Q: 如何卸载？

- **通过控制面板**: 设置 → 应用 → 应用和功能 → 找到 "ECompany Asst" → 卸载
- **通过安装程序**: 再次运行安装程序，选择 **卸载**

### Q: 如何更新版本？

下载新版本的安装包，直接运行安装即可覆盖旧版本。用户数据会保留。

## 启动方式

安装完成后有多种启动方式：

- **桌面快捷方式**: 双击桌面 "ECompany Asst" 图标
- **开始菜单**: 开始菜单 → ECompany Asst → ECompany Asst
- **任务栏**: 搜索 "ECompany Asst" 并启动

启动后将在系统托盘显示图标，右键托盘图标可进行快捷操作。
