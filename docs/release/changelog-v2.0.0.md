## 概述

ECompany Asst 是一款企业级 AI 助手桌面客户端，集成了智能对话、桌面操作、文件管理、工具扩展等核心能力。基于 OpenClaw 引擎驱动，通过 AI CEO Agent 实现自然语言的桌面智能操控。

## 新功能

### 🚀 核心功能

| 功能 | 说明 |
|------|------|
| **AI CEO 对话** | 自然语言交互，理解意图并执行操作 |
| **桌面操控** | 鼠标移动/点击、键盘输入、窗口管理、屏幕截图 |
| **文件管理** | 读写文件、目录遍历、JSON/CSV 解析 |
| **工具扩展** | 动态安装/卸载自定义工具（`tool_install` / `tool_uninstall`） |
| **分身协作** | 通过 Sub-Agent 并行执行任务 |
| **记忆引擎** | 持久化存储与语义检索 |
| **工具审批** | 敏感操作需用户授权确认 |

### 🔧 技术能力

- 支持 230+ 内置工具（文件操作、代码执行、网络请求等）
- 支持桌面截图 + 屏幕元数据自动采集
- 支持 `[CLICK:x,y]` 标记自动执行（LLM 分析坐标后自动点击）
- MCP 协议服务集成（238 个工具端点）
- 三通道工具注册架构（Handler + Schema + 路由表）

## 已知问题

- 截图坐标分析依赖 LLM 估算（没有集成 OCR/UIAutomation 视觉定位）
- 复杂 UI（如网页嵌套 iframe）定位精度有限
- 首次启动时后端初始化需要 5-10 秒
