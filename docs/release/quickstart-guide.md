# ECompany Asst — 快速上手指南

> 启动后的 5 分钟 —— 从连接到开始使用

---

## 启动与登录

1. 双击桌面快捷方式启动程序
2. 等待底部后端初始化完成（状态指示变绿）
3. 窗口自动打开，进入主界面

## 核心功能一览

### 🤖 AI CEO 对话

主界面左侧是对话面板，右侧是工具/信息面板。

**基本对话：**
```
你：帮我看看桌面上有什么
CEO：好的，我来截图分析...
      [自动截图 → 分析 → 返回描述]
```

**任务执行：**
```
你：帮我在桌面上打开 我的电脑
CEO：找到"此电脑"图标在 (100, 1050) 位置，双击打开...
      [自动截图 → 定位图标 → 双击]
```

### 🖱️ 桌面操作

CEO 可以控制鼠标、键盘和窗口：

| 操作 | 示例 |
|------|------|
| 移动鼠标 | "鼠标移到屏幕左上角" |
| 点击 | "双击桌面上的微信图标" |
| 截屏 | "截个屏给我看看" |
| 窗口管理 | "帮我打开任务管理器" |
| 快捷键 | "按下 Ctrl+C" |

### 📁 文件管理

CEO 可以读写文件、管理目录：

| 操作 | 示例 |
|------|------|
| 读取文件 | "帮我打开 D:\我的文档\readme.txt" |
| 写入文件 | "往桌面新建一个记事本文件，写点内容" |
| 查看目录 | "看看 D盘 里面有什么" |

### 🧩 工具扩展

CEO 可以安装和使用自定义工具：

```
你：安装一个新工具，功能是把汉字转成拼音
CEO：正在安装... 工具安装成功！现在你可以说"把'你好世界'转成拼音"
```

### 👥 分身协作

复杂任务可以拆解给多个 "分身" 并行执行：

```
你：帮我查一下今天的天气，同时整理桌面文件
CEO：我同时处理这两个任务...
     [分身A → 查询天气]
     [分身B → 整理桌面]
     汇总结果给你
```

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Enter` | 发送消息 |
| `Ctrl+L` | 清空对话 |
| `Ctrl+S` | 截屏当前屏幕 |
| `F11` | 切换全屏 |

## 常见使用场景

### 场景1：自动化操作

```
你：帮我登录一下公司 OA 系统
CEO：我需要在浏览器中操作，让我打开浏览器并定位登录页面...
     [自动打开浏览器 → 定位地址栏 → 输入网址 → 定位账号框 → 输入账号密码 → 点击登录]
```

### 场景2：文档整理

```
你：帮我把桌面上所有的 Word 文档按修改日期排序，列出前5个
CEO：[扫描桌面 → 过滤 .docx → 按修改时间排序 → 展示列表]
```

### 场景3：信息检索

```
你：昨天张三在群里说的那个方案，帮我查一下具体内容
CEO：[调取记忆引擎 → 搜索关键词"张三 方案" → 展示结果]
```

## 注意事项

- CEO 执行操作前会先截图分析，确保精准定位
- 涉及文件修改、外部网络请求等敏感操作需要你的授权
- 如果 CEO 执行有偏差，可以补充描述纠偏
