# eCompany v2.0 全面功能介绍

> 版本：2.0.0 | 构建日期：2026-06-19

---

## 一、核心架构

eCompany v2.0 是一个**全功能多模态 AI 集群管理桌面系统**，采用前后端分离架构，本地运行、数据自持。

```
用户浏览器（SPA） ←→ Node.js 后端（8005端口） ←→ AI 模型 API
                              ↕
                          SQLite 数据库
                          + 本地文件存储
                          + AI 记忆系统
```

| 层级 | 技术栈 | 说明 |
|:----|:-------|:----|
| 前端 | Vue 3 + Vue Router + Vue I18n + Vite | 单页应用，响应式 UI |
| 后端 | Node.js + 原生 HTTP Server | 无外部框架依赖 |
| 数据库 | better-sqlite3 | 本地嵌入式关系库 |
| 认证 | JWT | 支持 Bearer Token 白名单验证 |
| AI | DeepSeek / 通义千问 / 腾讯混元 / Ollama | 多模型路由 + 故障切换 |

## 二、八大核心功能

### 功能 1：CEO AI 智能调度系统 🧠

**对话式任务管理**，自然语言驱动团队协作。

- **任务创建**：`给小李分配一个前端优化任务` → 自动创建任务、通知执行人
- **进度追踪**：`查一下项目A的进度` → 实时展示各子任务状态
- **全员调度**：CEO 可并行管理多个 AI Agent（架构师、CTO、COO、安全专家等）
- **自动复盘**：任务完成后自动生成复盘总结
- **工具调用链**：CEO 自动调用 70+ 内置工具完成复杂任务（代码审查、知识检索、数据查询）

**适用场景**：项目管理、团队协调、自动化工作流编排

### 功能 5：BI 自动化规则引擎 ⚙️

**可视化流程编排**，零代码定义业务逻辑。

**节点类型**：
- **数据源**：API 请求、数据库查询、文件读取
- **变换**：数据提取、格式转换、运算处理
- **条件**：逻辑判断、范围检查、状态比对
- **通知**：Webhook 推送、渠道消息、邮件通知
- **等待**：定时延时、外部触发等待
- **输出**：文件写入、数据库存储、响应返回

**触发方式**：
- 定时触发（CRON 表达式）
- API 调用触发
- 事件驱动触发（错误、阈值、状态变更）
- 手动触发

**适用场景**：数据 ETL、自动报表、异常告警

### 功能 6：自适应进化系统 🌱

**AI Agent 学习与优化闭环**，让系统越用越聪明。

- **行为记录**：自动记录 Agent 决策轨迹和执行结果
- **参数调优**：基于历史表现自动调整模型参数
- **能力评估**：定期对每个 Agent 进行能力评分
- **进化历史**：记录每次优化变更，支持回滚
- **认知状态**：实时展示模型路由、负载均衡、故障切换状态

**适用场景**：系统持续优化、A/B 测试、自适应路由

### 功能 7：双模知识库 📚

**高性能知识检索**，倒排索引 + 语义搜索双引擎。

**词级搜索（倒排索引）**：
- 中文 2-gram 分词
- 英文单词提取
- Tag 和分类前缀搜索
- 加权排序（标题 > Tag > 内容）
- 响应时间 < 5ms（约 20,000 QPS）

**语义搜索（向量检索）**：
- Ollama nomic-embed-text 本地嵌入模型
- 768 维向量空间
- 混合搜索（BM25 + 向量）
- MMR 多样性重排序
- 时间衰减评分

**适用场景**：文档检索、FAQ 系统、智能客服知识库

---

### 功能 8：安全与认证 🔐

**多层次安全防护**（2026-06-19 安全审计后版本）。

**认证体系**：
- JWT Bearer Token 认证（非公共 API 端点强制验证）
- 白名单放行：登录/注册/聊天/流量/预检
- 认证异常直接 401 拒绝

**数据保护**：
- API 密钥 AES-256-CBC 加密存储
- 主密钥独立文件，已加入 .gitignore
- 数据库敏感字段清理

**代码安全**：
- SQL 参数化查询（预防注入）
- CSP 头部移除 unsafe-eval
- new Function() 安全检查过滤
- 认证 bypass 代码已移除

**配置安全**：
- JWT 硬编码回退密钥已移除
- 数据库降级 JSON Stub 改为拒绝启动
- 启动脚本端口检测不强制 kill

## 四、技术亮点

- **零外部框架依赖的后端**：HTTP 服务器全部用原生 `http` 模块实现
- **多模型故障切换**：主模型失败自动切换备选，保证服务的持续可用性
- **SSE 流式输出**：AI 对话支持流式响应，实时展示思考过程
- **热更新路由**：`registerRoute` 动态注册，模块加载即生效
- **双重记忆系统**：JSON 持久化 + SQLite 结构化存储 + OpenClaw 向量索引
- **熔断保护**：API 调用异常计数，超阈值自动切换线路
