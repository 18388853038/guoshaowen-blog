## 1. 系统概述

eCompany v2.0 是一个基于 Node.js 的多模态 AI 集群管理平台，内置以下核心子系统：

- **CEO AI 智能调度系统**：自然语言驱动的任务分发、进度追踪、状态监控
- **多渠道通讯桥接**：微信、钉钉、飞书、企业微信、QQ、Telegram、Discord 等
- **BI 商业智能仪表盘**：实时 API 流量监控、错误分析、模型用量统计
- **技能工作台**：80+ 内置 AI 技能（代码审查、API 测试、网页抓取、文档处理等）
- **自动化工作流引擎**：可视化流程编排、定时任务、条件触发
- **知识库引擎**：倒排索引 + 向量搜索的双模知识检索
- **自适应进化系统**：AI Agent 自动学习、参数调优、行为反馈闭环

eCompany 以本地桌面应用形式运行，所有数据存储于本地，AI 模型调用需自行配置 API 密钥。

## 3. 安装指南

### 3.1 标准安装

1. 双击运行 `eCompany-Setup-2.0.0.exe` 安装程序
2. 选择安装路径（默认：`C:\Program Files\eCompany v2.0`）
3. 等待安装完成
4. 安装完成后桌面将出现 `eCompany v2.0` 快捷方式

### 3.2 首次启动

1. 双击桌面快捷方式或 `Start eCompany.bat` 启动服务
2. 系统将自动打开浏览器访问 `http://localhost:8005`
3. 首次启动会自动初始化数据库和配置文件

### 3.3 端口说明

| 端口 | 用途 |
|:---:|:----|
| 8005 | eCompany 主服务（Web UI / API） |
| 11434 | Ollama 本地模型（可选） |

> 若端口被占用，可通过 `backend\config\server.json` 修改端口。

### 3.4 目录结构

```
eCompany v2.0/
├── backend/              # 后端服务
│   ├── server-modern.js  # 主服务入口
│   ├── modules/          # 功能模块（AI引擎、路由、认证等）
│   ├── data/             # SQLite 数据库
│   ├── memory/           # AI Agent 记忆文件
│   └── logs/             # 运行日志
├── frontend/             # 前端 SPA
│   └── dist/             # 编译后的静态资源
├── config/               # 用户配置文件
└── start.mjs             # Node.js 启动器（推荐）
```

## 4. 首次启动配置

### 4.1 API 密钥配置

1. 启动后进入 **设置 → 提供商密钥**
2. 依次填入各 AI 提供商的 API Key：
   - **DeepSeek**（推荐）：`sk-xxx` — 主要 AI 推理引擎
   - **阿里通义千问**（可选）：`sk-xxx` — 备用推理引擎
   - **腾讯混元**（可选）：`sk-xxx` — 备用推理引擎

### 4.2 JWT 认证密钥

- 系统内置随机 JWT 密钥，无需手动配置
- 如需自定义：设置环境变量 `JWT_SECRECT` 或在启动脚本中修改

### 4.3 通讯渠道配置（可选）

在 **渠道管理** 页面配置各通讯渠道的凭证：

| 渠道 | 需填内容 | 获取方式 |
|:----|:---------|:---------|
| 微信 | Bot Token + App ID | 微信开放平台 → 创建 Bot |
| 钉钉 | Client ID + Client Secret | 钉钉开放平台 → 机器人 |
| 飞书 | App ID + App Secret | 飞书开放平台 → 企业自建应用 |
| 企业微信 | Bot ID + Bot Secret | 企微后台 → 机器人管理 |
| QQ | Bot Token | QQ 开放平台 → QQ 机器人 |

## 5. 功能模块概览

### 5.1 主界面

启动后访问 `http://localhost:8005`，默认进入**工作台**页面。

**工作台布局**：
- **左侧**：聊天面板 — 与 CEO AI 对话，下达任务指令
- **右侧**：看板面板 — 项目进度、任务状态可视化

### 5.2 CEO AI 智能调度（聊天面板）

通过自然语言与 CEO AI 对话，可实现：
- `分派任务给小李，需求是xxx` — 创建并分配任务
- `查一下项目A的进度` — 实时查询团队任务状态
- `写一份周报` — 自动生成项目报告
- `帮我分析这段代码` — 调用代码审查技能

### 5.3 仪表盘

实时数据监控面板，展示：
- API 总请求数、成功率、失败率（实时累计）
- AI 模型调用统计（历史累计 + 分日明细）
- Token 消耗量（输入/输出）
- 各模型提供商使用分布

### 5.4 渠道管理

管理所有通讯渠道的绑定状态和凭证配置：
- 查看各渠道在线状态（🟢 在线 / 🔴 离线）
- 配置/更新渠道凭证
- 绑定渠道到指定 AI Agent

### 5.5 技能工作台

80+ 内置 AI 技能：
- Web 搜索与抓取、API 测试、代码审查
- 文档处理、数据库操作、Docker 管理
- 天气查询、备忘录、图表生成
- 安全审计、性能优化、国际化翻译

### 5.6 知识库

文档知识管理：
- 上传文档 → 自动提取关键词、摘要
- 倒排索引 + 向量双模搜索（语义检索）
- 支持 Tag / 分类目录浏览

### 5.7 BI 数据看板（Harness）

高级数据分析面板：
- 性能指标（延迟分布、吞吐量）
- 错误统计与趋势分析
- 模型评估（质量评分、响应评分）
- 边界状态监控
- 用户留存率趋势

### 5.8 自动化

可视化工作流引擎：
- **定时任务**：每日报表、定期备份、周期提醒
- **条件触发**：API 错误触发通知、流量阈值告警
- **数据变换**：提取/转换/通知等节点编排

### 5.9 进化系统

AI Agent 自适应进化平台：
- 行为轨迹记录与回放
- 自动参数调优
- 能力评估与优化建议
- 进化历史可视化

## 6. 常见问题

### Q：服务启动后浏览器无法访问？
检查端口 8005 是否被其他程序占用，或防火墙是否阻止。可在任务管理器中结束 `node.exe` 进程后重试。

### Q：AI 对话不回复？
检查 **设置** 中是否已配置 API Key，以及网络是否可访问对应服务。

### Q：如何更新？
下载最新安装包覆盖安装即可，配置和数据文件会自动保留。

### Q：如何完全重置？
删除 `backend/data/` 目录下的数据库文件和服务日志，重启即可恢复初始状态。

### Q：如何备份数据？
复制以下目录即可完成完整备份：
- `backend/data/` — 数据库
- `backend/memory/` — AI 记忆
- `backend/config/` — 用户配置
