## 📊 三、文档核心内容摘要

### 3.1 闭环模型

```
① 任务分配（小龙主Agent）
    ↓
② 子代理执行（check → claim → 执行 → write → complete）
    ↓
③ 成果提交（write_file → complete_claimed_task）
    ↓
④ 小龙审核（完整性/正确性/规范性/可读性/可执行性）
    ↓
⑤ 归档沉淀（标记完成 → 记避坑指南 → 更新知识库 → 汇报CEO）
```

### 3.2 子代理标准工作闭环（5步法）

| 步骤 | 工具调用 | 说明 |
|:---:|:--------:|:----|
| STEP 1 | `check_pending_tasks()` | 每次激活第一件事，检查待办任务 |
| STEP 2 | `claim_task(taskId)` | 领取任务，确认归属 |
| STEP 3 | 使用专业工具执行 | read_file/kb_search/query_experience/query_pitfalls 等 |
| STEP 4 | `write_file(filepath, content)` | **必须调用**，将成果写入文件系统 |
| STEP 5 | `complete_claimed_task(taskId, result, success)` | **必须调用**，回调小龙主Agent |

### 3.3 执行红线（禁止行为）

| ❌ 禁止行为 | 后果 |
|:----------:|:----:|
| 拒绝调用write_file | 成果不被认可，任务无效 |
| 跳过complete_claimed_task | 任务链断裂，CEO收不到通知 |
| 跨角色越权执行 | 产出质量不达标 |
| 超时未响应且不说明原因 | 触发重试/升级机制 |
| 成果未归档到正确目录 | 成果不可追溯 |
| 文件头部信息缺失 | 无法追溯责任人 |
