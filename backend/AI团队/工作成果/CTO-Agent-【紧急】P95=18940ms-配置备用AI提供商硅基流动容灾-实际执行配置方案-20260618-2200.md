## 二、硅基流动(SiliconFlow)配置方案

### 2.1 API Key 配置

硅基流动（SiliconFlow）是一个国内可访问的 AI API 聚合平台，支持多种模型。配置方式如下：

```json
{
  "providers": {
    "deepseek": {
      "api_key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
      "base_url": "https://api.deepseek.com",
      "models": ["deepseek-chat", "deepseek-coder"],
      "priority": 1,
      "status": "active"
    },
    "siliconflow": {
      "api_key": "sf-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
      "base_url": "https://api.siliconflow.cn/v1",
      "models": ["Qwen/Qwen2.5-72B-Instruct", "deepseek-ai/DeepSeek-V3"],
      "priority": 2,
      "status": "active"
    }
  }
}
```

> **获取硅基流动 API Key 的途径**：
> 1. 访问 https://siliconflow.cn 注册账号
> 2. 进入控制台 → API Keys → 创建新 Key
> 3. 硅基流动提供免费额度（注册即送），可直接使用
> 4. 如无法获取，需向 CEO/老板汇报申请

### 2.2 路由策略配置 - Fallback 模式

```json
{
  "router": {
    "strategy": "fallback",
    "primary": "deepseek",
    "fallback": ["siliconflow"],
    "fallback_mode": "sequential",
    "timeout_ms": 5000,
    "retry_on_timeout": true,
    "max_retries": 2
  }
}
```

**路由逻辑**：
1. 请求优先发往 `deepseek`（主提供商）
2. 如果 deepseek 在 5000ms 内未响应 → 触发超时熔断
3. 自动切换到 `siliconflow`（备用提供商）
4. 如果 siliconflow 也超时 → 返回降级响应（缓存/默认回复）

### 2.3 超时熔断机制配置

```json
{
  "circuit_breaker": {
    "per_request_timeout_ms": 5000,
    "consecutive_failures_threshold": 5,
    "error_rate_threshold_percent": 50,
    "error_rate_window_minutes": 10,
    "half_open_after_ms": 120000,
    "health_check_interval_ms": 30000,
    "health_check_retries": 3
  }
}
```

**熔断级别**：

| 级别 | 触发条件 | 动作 |
|:----:|:---------|:-----|
| **L1 - 单次超时** | 单请求 > 5000ms | 切换至硅基流动重试 |
| **L2 - 连续熔断** | 连续 5 次超时 | 熔断 DeepSeek 120s |
| **L3 - 错误率熔断** | 10 分钟内错误率 > 50% | 全量切至硅基流动 |

### 2.4 模型映射配置

将 DeepSeek 模型映射到硅基流动的等效模型：

| DeepSeek 模型 | 硅基流动等效模型 | 说明 |
|:-------------|:----------------|:-----|
| `deepseek-chat` | `Qwen/Qwen2.5-72B-Instruct` | 通义千问72B，综合能力强 |
| `deepseek-coder` | `deepseek-ai/DeepSeek-V3` | DeepSeek V3 模型 |
| `deepseek-reasoner` | `Qwen/QwQ-32B-Preview` | 推理模型替代 |
