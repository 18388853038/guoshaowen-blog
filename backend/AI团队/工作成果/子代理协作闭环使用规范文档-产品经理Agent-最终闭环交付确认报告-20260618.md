### 核心闭环流程（5步法）

```
STEP 1: check_pending_tasks    → 每次激活第一件事：检查待办任务
STEP 2: claim_task             → 领取任务，确认归属
STEP 3: 执行任务               → 使用专业工具完成工作
STEP 4: write_file             → 【必须】将成果写入文件系统
STEP 5: complete_claimed_task  → 【必须】回调小龙主Agent
       ↓
回到 STEP 1，循环检查下一个任务
```

### 五大核心原则

| 原则 | 说明 |
|:----:|------|
| **主控调度** | 小龙主Agent统一分配任务，子代理不越权 |
| **闭环必达** | 每项任务完成后必须调用 `complete_claimed_task` 回调 |
| **成果物化** | 所有产出必须通过 `write_file` 写入 `AI团队/工作成果/` 目录 |
| **知识沉淀** | 踩坑经验通过 `add_pitfall` 记录到避坑指南 |
| **可追溯性** | 每个任务从领取到完成形成完整链路记录 |
